CARD SHOW: AFTER HOURS — WEBSITE

This folder is your ready-to-publish static website.

GitHub Pages steps:
1. Sign in to github.com using a permitted account.
2. Create a new PUBLIC repository named card-show-after-hours.
3. Upload index.html into the repository root. Commit it.
4. Open Settings > Pages > Build and deployment > Source: Deploy from a branch.
5. Select branch main, folder /(root), and Save.
6. Wait for GitHub Pages to display your site URL: https://YOUR-USERNAME.github.io/card-show-after-hours/

Use your own GitHub username where shown. The game works as an ordinary webpage without installing Godot. School filtering may block individual domains.

IMPORTANT: Save data is local to each browser/device, so Chromebook progress will not automatically sync with home PC or phone. The game is a scripted simulation, not OpenAI-powered yet. Hosted images require an internet connection and may disappear if third-party sources change.

If you later connect an AI provider, NEVER place API keys inside index.html. A secure backend is required.
